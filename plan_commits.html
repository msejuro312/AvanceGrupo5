Manuel agrega sus endpoints al final del archivo creado por Isaac, después de la línea 46 (endpoint agregarDetalle):

// (Todo el contenido anterior creado por Isaac se mantiene intacto) // ────────────────────────────────────────── // AGREGADO POR MANUEL (después de línea 46) // ────────────────────────────────────────── @PutMapping("/{idOrden}/estado") public ResponseEntity<?> cambiarEstado( @PathVariable Integer idOrden, @RequestParam String estado) { ... } @GetMapping("/usuario/{idUsuario}") public List<OrdenCompra> historial( @PathVariable Integer idUsuario) { ... } @GetMapping("/{idOrden}") public ResponseEntity<OrdenCompra> detalle( @PathVariable Integer idOrden) { ... } // Fin del archivo // Ahora el controlador tiene los 5 endpoints completos
